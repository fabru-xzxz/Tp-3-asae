# Tp-3-asae
Sistema de Gestión de Tareas

Descripción

Este proyecto consiste en un programa desarrollado en Java por consola que permite administrar una lista de tareas.

Funciones principales

- Agregar tareas.
- Mostrar todas las tareas registradas.
- Contar la cantidad de tareas.
- Buscar tareas por su nombre.
- Salir del programa.

Tecnologías utilizadas

- Java.
- Apache NetBeans IDE 7.3.1.
- Git.
- GitHub.

Cómo ejecutar el programa

1. Abrir el proyecto en NetBeans.
2. Ejecutar el archivo "Main.java".
3. Seleccionar una opción del menú.
4. Seguir las instrucciones que aparecen en consola.
